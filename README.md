# Projet Zappy

## Contexte
Le projet Zappy consiste à réaliser un jeu, avec 3 parties :
 
* La partie **serveur**, qui gère la vie des joueurs, le monde, les ressources et les actions, en interprétant les commandes envoyées.
* La partie **IA**, qui prend les décisions du joueur. Dans ce jeu, l'humain ne joue pas directement : une fois lancée, l'IA pilote le joueur de manière totalement autonome et envoie au serveur des commandes selon les actions qu'elle décide d'effectuer.
* La partie **GUI**, qui affiche ce qui se passe dans le monde, notamment les joueurs qui bougent et qui effectuent des actions. Cette partie n'était pas à faire pour notre part.
