# Documentation d'installation
 
## 1. Installation des dépendances
Pour installer ce projet, vous devez installer sur votre machine les dépendances suivantes :
* Python3
* Une libC de type glibc, comme libc6-dev
* Un compilateur C : par défaut c'est `epiclang`, un clang modifié, mais vous pouvez le remplacer dans les Makefiles par `gcc` ou simplement `clang`
## 2. Téléchargement du projet
Exécutez la commande suivante :
```bash
git clone git@github.com:EpitechPGE2-2025/G-YEP-400-LIL-4-1-zappy-12.git
```
ou bien allez sur le bouton vert `<> Code`, puis cliquez sur `Download ZIP` (ou « Télécharger en ZIP » si votre page GitHub s'affiche en français).
 
## 3. Aller dans le dossier du projet
Exécutez la commande suivante :
```bash
cd G-YEP-400-LIL-4-1-zappy-12
```
 
Vous pouvez maintenant retourner à la [documentation principale](../README.md).
